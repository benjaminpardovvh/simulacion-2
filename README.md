# Librería Horizontes - Sitio Web Front-End

Librería Horizontes es una plataforma web orientada al catálogo y selección de libros en línea. El proyecto ofrece una interfaz donde los usuarios pueden explorar obras organizadas por categorías, acceder a libros recomendados y gestionar una lista de selección personal.

## Características

* **Navegación por Categorías:** Clasificación rápida de la literatura disponible.
* **Módulo de Selección:** Contador dinámico para los libros agregados por el usuario.
* **Sección de Recomendados:** Tarjetas interactivas con detalles de las obras destacadas (`Cien años de soledad`, `Sapiens`, `El Principito`).
* **Registro / Login:** Formulario de acceso para usuarios registrados.
* **Diseño Responsivo:** Adaptación gráfica para distintos tamaños de pantalla.

---

## Categorías Disponibles

El catálogo clasifica los libros en las siguientes secciones principales:

* Novelas
* Ciencias
* Historia
* Tecnología
* Arte
* Infantil
